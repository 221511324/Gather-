# Gather — Sprint 1 

## Project Overview

Gather is a group food ordering application developed as a senior software engineering project at Prince Sultan University (PSU). It aims to simplify group food ordering by allowing users to manage their accounts and participate in shared ordering sessions.

Sprint 1 focuses on implementing the foundational features required for users to access the application, manage their profiles, and create or join group sessions.

## Sprint 1 Features

- **User Registration:** Create a new user account.
- **User Login:** Access the application using registered credentials.
- **View Profile:** View personal account information.
- **Update Profile:** Edit and save profile information.
- **Create Group Session:** Allow a host to create a group ordering session with a unique four-digit session code.
- **Invite Members:** Invite registered users to participate in a group session.
- **Join Group Session:** Join an existing session using a valid session code or invitation link.

## Technology Stack

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Database and Backend Services:** Firebase
- **Development Environment:** Visual Studio Code
- **Version Control:** GitHub
- **Testing:** Unit Testing and Integration Testing

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Android Studio or an Android emulator

### Installation and Setup

1. Clone the Repository:

   ```bash
   git clone https://github.com/221511324/Gather-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Gather-
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Check the development environment:

   ```bash
   flutter doctor
   ```

5. Run the application:

   ```bash
   flutter run
   ```

## Sprint 1 Testing

Sprint 1 includes unit testing for individual application components and integration testing to verify that related features work together.

Run unit tests:

```bash
flutter test
```

Run integration tests:

```bash
flutter test integration_test/app_flow_test.dart
```

The Sprint 1 test report documents test cases, execution results, and identified defects. Bugs are tracked through GitHub Issues, including their resolution status.

## Development Methodology

The project follows the Agile Scrum methodology. Sprint 1 establishes the application's foundational functionality through user stories, implementation, testing, and defect tracking.
