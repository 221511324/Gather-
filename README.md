# Gather — Group Food Ordering Application

## Project Overview

Gather is a group food ordering application developed as a senior software engineering project at Prince Sultan University (PSU). It helps users organize group food orders, manage their profiles, explore restaurants, and participate in shared ordering sessions.

The project is developed incrementally using Agile Scrum. The repository contains the implementation of Sprint 1 and Sprint 2 in separate folders.

## Project Objectives

- Simplify the group food ordering process.
- Allow users to manage their accounts and profile information.
- Enable users to create and join group ordering sessions.
- Provide restaurant browsing and food ordering functionality.
- Support order management and order tracking.

## Sprint 1 Features

Sprint 1 focuses on the foundational functionality of the application.

- **User Registration:** Create a new user account.
- **User Login:** Access the application using registered credentials.
- **View Profile:** View personal account information.
- **Update Profile:** Edit and save profile information.
- **Create Group Session:** Allow a host to create a group ordering session with a unique four-digit session code.
- **Invite Members:** Invite registered users to participate in a group session.
- **Join Group Session:** Join an existing session using a valid session code or invitation link.

## Sprint 2 Features

Sprint 2 expands the application with additional screens and functionality for the group food ordering experience.

- **Restaurant Browsing:** Explore restaurant-related information.
- **Search:** Search for relevant items or information.
- **Shopping Cart:** Manage selected food items.
- **Checkout:** Access the checkout process.
- **Favorites:** Access favorite items or restaurants.
- **Orders and Tracking:** View order-related information and tracking features.
- **Group Sessions:** Access group ordering functionality.
- **User Profile:** Manage profile-related information.
- **Admin:** Access the application's administration features.
- **Help:** Access help-related functionality.

Sprint 2 also includes supporting models, services, and tests to support the application's functionality.

## Technology Stack

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Backend and Database Services:** Firebase
- **Development Environment:** Android Studio or Visual Studio Code
- **Version Control:** GitHub
- **Testing:** Unit Testing and Integration Testing

## Project Structure

The repository contains two separate project folders:

- **Root directory:** Contains the Sprint 1 project files.
- **Sprint2/:** Contains the Sprint 2 Flutter project, including its application screens, models, services, and tests.

The two project versions are kept separate to preserve the original Sprint 1 implementation while including the additional Sprint 2 work.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- An Android emulator or compatible device

### Running Sprint 1

1. Clone the repository:

   `git clone https://github.com/221511324/Gather-.git`

2. Navigate to the repository directory:

   `cd Gather-`

3. Install dependencies:

   `flutter pub get`

4. Run the application:

   `flutter run`

### Running Sprint 2

1. Navigate to the Sprint 2 project directory:

   `cd Sprint2`

2. Install dependencies:

   `flutter pub get`

3. Check the development environment:

   `flutter doctor`

4. Run the application:

   `flutter run`

Run the commands from the appropriate project directory.

## Testing

The project includes tests for application components and related functionality.

To run the tests for Sprint 1, navigate to the repository root and run:

`flutter test`

To run the tests for Sprint 2, navigate to the `Sprint2` directory and run:

`flutter test`

Test results and identified defects should be documented and tracked through the project's testing activities and GitHub Issues.

## Development Methodology

The project follows the Agile Scrum methodology. Sprint 1 established the foundational features, while Sprint 2 expanded the application with additional screens and group food ordering functionality.
